# Axiomancy: The Scholar's Deck

Educational STEM card battler built with React, TypeScript, Vinext, Cloudflare Worker and D1.

## Quick start

```bash
npm ci
npm run dev
```

For the complete Vietnamese setup guide, Windows/WSL commands, database configuration, testing and GitHub instructions, read [Read.md](Read.md).

## Main commands

```bash
npm run dev
npm run lint
npm test
npm run build
npm run start
```

> This is a full-stack Worker application. GitHub Pages alone cannot run its API routes or D1 persistence layer.
